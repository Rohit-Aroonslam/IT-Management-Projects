## What was done
An information security governance framework for Cortexa AI, a fictional mid-sized ML company. It covers the Enron governance-failure case study (King IV), COBIT IT governance, InfoSec roles, the Direct-Execute-Control model, standards comparison, board and policy structure, operational controls, IT risk management, and a SETA programme.
